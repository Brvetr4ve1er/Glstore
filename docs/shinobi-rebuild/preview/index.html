01

Brand expression 忍

Anime warrior streetwear. The brand voice is direct, French-first, scarcity-aware. The visual system is restrained — one red, one ink, one paper, one wave pattern. Kanji 忍者 appears as an accent next to section titles; never as body content. The mascot is a friend to the wordmark, not a mascot-takeover.

Forge ton univers

A signature seigaiha-red band. White wave pattern at 22 % opacity over #CC0000. Used once or twice per page — never as a full section background.

L'univers Otaku 忍者

Dark indigo band with the white-on-indigo seigaiha. The home page's "drops" section reads on a band like this.

Notre Catalogue

The default surface — warm washi paper, ink seigaiha at 10 % opacity, body-content sits cleanly on top.

13

Motion

Two named curves. Shuriken snaps in. Koi overshoots and settles. Hover the cards to feel each.

Shuriken — primarycubic-bezier(0.16, 1, 0.3, 1)

Cards, nav reveal, page transitions. Snap in, instant settle.

Koi — delightcubic-bezier(0.34, 1.56, 0.64, 1)

Size selectors, cart badge, "ajouter" success. Overshoots, returns.

/* Custom Builder price quote — single function */
function quoteCustom(cfg, bases) {
  const base = bases.find(b => b.id === cfg.baseId);
  let total = base.basePrice;
  if (cfg.doubleSide && base.doubleSideAllowed) total += 500;
  return total;
}
