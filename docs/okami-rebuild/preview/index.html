01

Aesthetic Direction

Dark anime streetwear brutalism. Japanese manga print culture (halftone texture, monochrome restraint) crossed with Western streetwear loudness (oversized condensed type, brutal letter-spacing, white-on-void contrast). Mood: gritty, confident, underground, scarcity-driven. Product art carries all the colour; chrome stays near-monochrome so a grid of tees reads like a gallery wall.

09

Signature Interactions

The two patterns that define the whole feel.

① Greyscale → Colour
Product art defaults to filter: grayscale(0.95) brightness(1.1). On hover (or focus-within) → grayscale(0) + scale(1.10); greyscale transitions 0.4s ease, scale 0.5s expo. Sold-out = grayscale(1) brightness(0.5), permanent. Hover the product grid above to feel it.
② 3D Card Flip — perspective: 1000px + preserve-3d + backface-hidden, 700 ms --ease-expo. Hover or tab to the card below ↓

10

Motion System

Two custom bezier curves, one infinite logo pulse, hover transitions ~300 ms. Hover the cards to feel each curve.

Expo Out — primary cubic-bezier(0.16, 1, 0.3, 1)

Product hover, nav reveal, page transitions. Snappy in, instant settle.

Spring — delight cubic-bezier(0.34, 1.56, 0.64, 1)

Size select, cart badge, add-to-cart. Overshoots, bounces back.

Logo Pulse — infinite 1.5s ease-in-out infinite

scale 0.85 → 1.10, opacity 0.5 → 1.0. Breathing brand mark.

OKAMI
  • Card image zoom — scale-110 · 700 ms expo
  • Category shine sweep — white/10 gradient · opacity 0 → 1 · 500 ms
  • Image brighten — overlay black/30 → black/10 · 300 ms
  • Button press — active:scale-95
  • Marquee — translateX 0 → -50% · linear infinite
  • Page transition — translate-y 200px → 0 + opacity fade

Drop-in Tokens

/* OKAMI v2 — source-verified tokens */
@font-face { font-family: OKAMI;      src: url(/assets/font/OKAMI.otf)      format("opentype"); font-display: swap; }
@font-face { font-family: Streetwear; src: url(/assets/font/streetwear.ttf) format("truetype"); font-display: swap; }
@font-face { font-family: Inter;      src: url(/assets/font/inter.ttf)      format("truetype"); font-display: swap; }

body {
  background-color: #1E1623;
  background-image:    url(/assets/icons/wallpaper.svg);   /* ✦ external asset, NOT a CSS gradient */
  background-position: top;
  background-size:     cover;
  background-attachment: fixed;                            /* ✦ pinned parallax */
  font-family: OKAMI, -apple-system, sans-serif;
  color: #fff;
}

:root {
  --bg-base: #1E1623; --bg-deep: #0A050D; --bg-dark: #0D0B14;
  --bg-mid:  #1A1520; --bg-card: #251F2B; --bg-hover:#2A2533;

  --green: #00C758; --red: #FB2C36; --orange: #FE6E00;
  --amber: #F59E0B; --yellow: #EDB200; --purple: #AC4BFF; --blue: #3080FF;

  --ease-expo:   cubic-bezier(0.16, 1, 0.3, 1);
  --ease-spring: cubic-bezier(0.34, 1.56, 0.64, 1);
}

/* ✦ THE signature — greyscale → colour */
.product-img            { filter: grayscale(0.95) brightness(1.1);
                          transition: filter 0.4s ease, transform 0.5s var(--ease-expo); }
.product:hover .img      { filter: grayscale(0); transform: scale(1.10); }
.product.sold .img       { filter: grayscale(1) brightness(0.5); }

/* ✦ 3D flip */
.flip                   { perspective: 1000px; }
.flip-inner             { transform-style: preserve-3d; transition: transform 0.7s var(--ease-expo); }
.flip:hover .flip-inner { transform: rotateY(180deg); }
.flip-face              { backface-visibility: hidden; }

/* logo pulse */
@keyframes logoPulse {
  0%   { opacity: 0.5; transform: scale(0.85); }
  50%  { opacity: 1;   transform: scale(1.10); }
  100% { opacity: 0.5; transform: scale(0.85); }
}
