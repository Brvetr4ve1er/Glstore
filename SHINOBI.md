# SHINOBI (lives on branch `claude/shinobi-shop-rebuild`)

This branch contains a standalone anime-streetwear website for
**SHINOBI Shop** (Algiers). It is additive — it does not touch any
existing Glstore code.

- **The website (deploy this):** [`apps/site/`](./apps/site/) — a
  self-contained Astro static site. `cd apps/site && npm install &&
  npm run dev`.
- **Design + planning docs:** [`docs/shinobi-rebuild/`](./docs/shinobi-rebuild/)

➡️ **To pull SHINOBI out into its own repo and remove it from Glstore,
read [`docs/shinobi-rebuild/BRANCH-CONTEXT.md`](./docs/shinobi-rebuild/BRANCH-CONTEXT.md).**
That file is the complete inventory + extraction guide.
